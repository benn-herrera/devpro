## American English spellings

All tracked text uses American spellings. `just spellings` lists every tracked line the pattern
still matches; it exits zero whatever it lists, so it is a listing to read against the survivor
catalog below, not a gate, and is run after any text edit. The check skips the files that must
hold or quote a British form, each with its holding: the justfile, which holds the pattern; this
leaf, which holds the catalog; and the plan, design and review under way (`ACTIVE_*`), which quote
the forms. A hit outside them is one of two exceptions, and its case names the act: a file that
must quote a British form is skipped by the justfile, so add the file to the recipe's pathspecs;
an American form the pattern over-matches enters the catalog, so add the word here. The catalog
holds the one word no stem can spare: `misspelt`, a code name — the test symbol at
`tests/test_plugins.py:45` and `:46` — whose prose occurrences still match and change to
`misspelled`.
