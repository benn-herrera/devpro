### A harness resource's floor is behavioral

A version a harness resource names states what the resource has been used with most, developed over
time against the host as the host ships it; it is a testing claim, not a compatibility promise.
Versions below or above may work, unverified — your mileage may vary, the standard disclaimer — and
no sentence in a resource turns its version into a guarantee, least of all for behavior the host
owns. Where a resource depends on a host behavior, it states where that behavior was observed, as
observation: opencode's entry names 2.4.1, what it has been used with most, and its dispatch nudge
was observed working from 2.3.0, where the `subagent` call started returning at once.
