# A harness resource's version claims testing

A version this project's harness resources name states what the resource has been used with most:
a testing claim, not a compatibility promise. Versions below or above may work, unverified; a
resource's version line says so in one phrase, "your mileage may vary". No other sentence in it
turns the version into a guarantee, least of all for behavior the host owns. Where a resource
depends on a host behavior, its line notes where that behavior was observed working from:
opencode's entry names 2.4.1, what it has been used with most — developed over time with opencode —
and its dispatch nudge is noted "observed working from 2.3.0", where the `subagent` call started
returning at once.
