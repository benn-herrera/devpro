# A narrowed format names the inputs it refuses

A format change that narrows the set of inputs a tool expresses — a field it no longer accepts, a
document shape it no longer writes — names the inputs that no longer fit, and the tool refuses them
by name rather than expressing them wrongly or leaving them out.

R11 is the worked instance: a title-less document dices to exit 2 with `volume b: no opening
level-1 heading` (`dicedoc.py`) and nothing written.
