# Split level

`dice` and `undice` take the option `--split-level <level>`, which sets the
deepest split level ([which headings split](../../../PROJECT_DOCS/SPEC/dicing-and-checks/the-diced-tree/which-headings-split.md#which-headings-split)): `2`, `3` or `4`,
default `4`; any other value is a usage error.
